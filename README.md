# 末栏 · ARG 三部曲

一个不依赖豆包妙搭、不依赖任何后端或构建工具的纯静态网页恐怖解谜 ARG。

> 神一直在沉睡。人类的献祭，只是蚊子。

本项目根据《末栏·ARG 完整开发文档》重构，包含一周目、二周目、双视角劝阻、四个结局、终端对话、走廊场景、线索栏与程序化音效。可以直接部署到 GitHub Pages。

---

## 一、直接运行

最简单的方式：双击 `index.html`，用 Chrome / Edge / Safari / Firefox 打开。

更推荐在本地启动一个静态服务器（避免少数浏览器对 `file://` 的 localStorage 限制）：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

不需要安装 npm 依赖。

---

## 二、部署到 GitHub Pages

1. 新建一个 GitHub 仓库（例如 `molan-arg`）。
2. 把以下内容全部上传到仓库根目录：
   - `index.html`
   - `css/`
   - `js/`
   - `assets/`
   - `.nojekyll`
   - `README.md`（可选）
3. 打开仓库 **Settings → Pages**。
4. **Build and deployment** 选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/ (root)`，保存。
6. 等待 1–2 分钟，访问 `https://你的用户名.github.io/molan-arg/`。

`.nojekyll` 用于跳过 GitHub Pages 的 Jekyll 处理，请保留。

> 站点使用相对路径，放在仓库根目录或任意子目录都可以。不要用 GitHub Actions 构建，本项目没有构建步骤。

## 四、操作说明

- 左下角 **圆形喇叭**：开关声音。第一次点击页面后音频才会启动（浏览器自动播放限制）。
- 右下角 **线索**：打开已记录线索。收起后只保留一个小红点。
- 左上角 **返回**：回到上一级页面。不同场景的返回逻辑已经单独处理。
- 所有按钮支持键盘 `Tab` / `Enter`，弹窗支持 `Esc` 关闭。
- 手机端按钮高度不小于 48px；底部固定控件不会遮挡主要操作（终端页已单独留出安全区）。

存档键：

- `molan_arg_save_v2`：主线进度、线索、二周目选择、结局收集
- `molan_arg_muted`：声音开关
- `molan_has_completed`：兼容旧版的通关标记

清除进度：在标题页点击 **重新开始**，确认即可。也可以在浏览器开发者工具中执行：

```js
localStorage.removeItem('molan_arg_save_v2');
localStorage.removeItem('molan_has_completed');
location.reload();
```

## 六、四个结局

| 结局 | 触发条件 |
|---|---|
| 坏结局「它记得你来过」 | 最终选择「去殡仪馆」 |
| 假结局「你醒了」 | 最终选择「随手拍下来」 |
| 中间结局「你只救回一个」 | 只劝阻沈迟或沈搏其中一人，然后选择「不去，就这样活下去」 |
| 真结局「第一次为自己跳」 | 二周目同时劝阻两人，然后选择「不去，就这样活下去」 |

一周目没有劝阻机会，所以「不去」在没有任何劝阻时是锁定的。完成任意结局后会开启二周目；二周目通关后仍可继续进入新的周目。

坏结局会请求一次网络出口城市，用于显示当地殡仪馆。该请求只在玩家点击 **允许它找到你** 时发出；如果请求失败或玩家拒绝，会退回手动输入城市，或显示「我找不到你们的殡仪馆」。城市只用于本地生成文字，不会上传到本项目的服务器（本项目没有服务器）。

## 八、修改与扩展

- 改剧情 / 谜题 / 答案：编辑 `js/data.js`。
- 改颜色、排版：编辑 `css/style.css` 顶部的 `:root` 变量。
- 改场景流程：编辑 `js/app.js` 中的 `SCENES` 与 `handleAction`。
- 新增谜题时，记得同步修改 `D.clueDefs` 和对应表单的 `handleForm` 分支。
- 音效全部由 `js/audio.js` 合成，不需要额外的音频文件。
